NIGHT CITY HOLO-OS :: AUDIO SLOT MANIFEST
=========================================

Drop your own audio files into THIS folder (app/src/main/res/raw/) before building.
Every slot is optional. A slot with no file falls back to a procedurally synthesized
placeholder tone generated on-device, so the app always builds and always has a sound.
You can also skip this folder entirely and import files at runtime from the
AUDIO tab (file picker). Imported files override bundled ones.

RULES
  * Use the exact base name below. Supported extensions: .ogg  .mp3  .wav  .m4a  .flac
  * Lowercase letters, digits and underscores only (Android resource naming rules).
  * ONE file per slot: cue_eddie_transfer.ogg and cue_eddie_transfer.mp3 together
    is a "Duplicate resources" build error.
  * Short cues (< 2 s) work best for everything except the ringtone and alarm.

WHERE EACH SLOT GOES
  Holocall Ringtone          -> system default ringtone      (needs WRITE_SETTINGS)
  Notification Chirp         -> system default notification  (needs WRITE_SETTINGS)
  V's Apartment Alarm        -> system default alarm sound   (needs WRITE_SETTINGS)
  Eddie Transfer / New Gig   -> played by the notification listener per app
  Relic Malfunction / Link   -> played by the power-event monitor

The mapping lives in domain/model/AudioCue.kt (rawResourceName) if you want to rename slots.
Only bundle audio you have the rights to use.
